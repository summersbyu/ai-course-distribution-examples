# Stage 1 · Power user: a shared prompt library

**What's shared:** text. Prompts, prompt templates, and the instructions behind a Claude Project.
**Where it lives:** a folder like this one in a GitHub repository. A shared Google Drive folder also works.
**Hosting needed:** none.

| File | What it is |
| --- | --- |
| [`prompts/flux-explanation.md`](prompts/flux-explanation.md) | A structured prompt with context, task, constraints, a built-in self-check, and an output format |
| [`prompts/audit-inquiry-prep.md`](prompts/audit-inquiry-prep.md) | A prompt for planning an audit inquiry |
| [`prompts/project-instructions-ar-analyst.md`](prompts/project-instructions-ar-analyst.md) | Standing instructions to paste into a Claude Project |

## How a classmate uses one

1. Open the file on GitHub and click the copy button.
2. Paste it into Claude and fill in the bracketed parts.

## Why GitHub instead of Drive, even at this stage

- Every change is saved with who made it and why, so students can see how a prompt improved over time.
- Students will need GitHub at every later stage, so starting here makes the later steps familiar.
- A good prompt that gets reused often is the starting point for a skill (see Stage 2).
